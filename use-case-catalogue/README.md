# AI & Automation Use Case Catalogue (600 use cases)

A structured catalogue of **600 candidate use cases**: 75 for each of 8 functions (Data, Marketing, Product, Operations, Sales, Finance, HR, IT).

- **Automation level:** 380 full automation, 220 half automation (a person reviews or approves).
- **Tools:** Dust (assistants with a knowledge base), Gemini Gem (drafting, analysis), Zapier (triggers, routing, notifications), n8n (data workflows and integrations).
- **Flags:** data sensitivity (GDPR or financial controls) and human-review requirement.
- **Prioritisation columns:** Value, Effort, Status, Notes (to fill in).

File: `AI_Automation_Use_Case_Catalogue_600.xlsx` (sheets: Legend, Summary, Use Cases).

> This is a framework and idea catalogue. About 100 of these ideas come from real discovery work documented at ManoMano Colibri (HR); the rest are candidate use cases, not delivered projects.

## How to use it
1. Filter on Value = High and Effort = Low for quick wins.
2. Start with full automation and low data sensitivity.
3. For half automation, define who reviews and how fast.
4. Move selected cases to POC and record the results in this repo.
